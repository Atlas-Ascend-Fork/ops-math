## Function

Returns a random number tensor with values drawn from independent normal distributions of the given mean (float) and standard deviation (float).

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnNormalFloatFloatGetWorkspaceSize" API to obtain the workspace size required for the computation and the executor containing the operator computation flow, and then call the "aclnnNormalFloatFloat" API to perform the computation.

```Cpp
aclnnStatus aclnnNormalFloatFloatGetWorkspaceSize(
  float           mean,
  float           std,
  int64_t         seed,
  int64_t         offset,
  aclTensor       *out,
  uint64_t        *workspaceSize,
  aclOpExecutor   **executor)
```

```Cpp
aclnnStatus aclnnNormalFloatFloat(
  void           *workspace,
  uint64_t       workspaceSize,
  aclOpExecutor  *executor,

```

  return 0;
}
