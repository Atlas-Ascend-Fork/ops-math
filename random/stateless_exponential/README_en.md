## Function Description

- Operator function: generates random numbers that follow the exponential distribution with the parameter `lambd` based on the Philox4x32-10 PRNG, and fills the input tensor `self` in place with random numbers that follow the `Exp(lambd)` distribution. This operator is an internal service operator used by the without-replacement sampling path of the `aclnnMultinomialTensor` API on Ascend 950 (it generates exponentially distributed random perturbations for the subsequent `div + argmax/topk` to complete without-replacement multinomial sampling).
- Computation formula:

  $$
  x = -\frac{1}{\lambda} \ln(u), \quad u \sim U(0, 1]
  $$

  Here, `u` is generated by the Philox4x32-10 PRNG, and `lambd > 0` is the rate parameter of the exponential distribution.

## Constraint Description

1. `self` supports only FLOAT16/BFLOAT16/FLOAT, the ND format, and at most 8 dimensions; non-contiguous inputs are converted to contiguous ones by AutoContiguous.
2. `lambd` must be > 0.
3. `offset` must be a multiple of 4.
4. Only Ascend 950 is supported. Graph building (op_graph), the L2 APIs, and non-contiguous tensors are not supported.
