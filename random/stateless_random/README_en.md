## Function Description

- Operator function: returns random numbers drawn from the discrete uniform distribution over the range [from, to - 1].
- Computation formula:
  $$
  output[i] = X \% (to - from) + from
  $$
  Here, X is a uint32 random number generated by the Philox random number generator.

## Constraint Description

- offset is a multiple of 4.
- The output tensor supports 0 to 8 dimensions.
- from must be less than to. The range specified by from/to-1 cannot exceed the range of the self data type.
