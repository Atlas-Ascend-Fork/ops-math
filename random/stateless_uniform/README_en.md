## Function Description

- Operator function: generates a random number tensor that follows the uniform distribution based on the Philox4x32-10 pseudo-random number generation algorithm. The random values are in the range [from, to).

- Computation formula:

  $$
  y_i = u_i \times (to - from) + from, \quad u_i \sim \text{Uniform}(0, 1]
  $$

  Here, $u_i$ is generated by the Philox4x32-10 algorithm. The normalization method is the same as that of the competitor curand_uniform: $u = x \times 2^{-32} + 2^{-33}$.

## Constraint Description

- offset must be a multiple of 4.
- The output tensor supports 0 to 8 dimensions.
- from must be less than or equal to to, and to - from cannot exceed the representation range of the output data type.
