## Function Description

- Operator function: RReLU is a randomized variant of leaky ReLU: during training, for each non-positive input element, a slope factor is sampled from the uniform distribution U(lower, upper). While producing the activation output y, this operator also records the slope actually used at each position into the output noise for backward propagation and other subsequent use.
- Formula (training semantics):

  $$
  y[i] =
  \begin{cases}
  x[i] \cdot r[i], & x[i] \leq 0 \\
  x[i], & x[i] > 0
  \end{cases}
  \qquad
  noise[i] =
  \begin{cases}
  r[i], & x[i] \leq 0 \\
  1, & x[i] > 0
  \end{cases}
  $$

- Here $r[i]$ is a uniform random number on $[lower, upper]$ (floating-point rounding may touch the upper bound), generated by a deterministic random stream determined jointly by seed and offset, independent of the input data: $r[i] = (T)u[i] \cdot (upper - lower) + lower$, where $u[i] \in (0, 1]$.
- Branch semantics: $x[i] = 0$ takes the random-slope branch; when $x[i]$ is NaN, the comparison is always false and the positive branch is taken ($y[i] = NaN$, $noise[i] = 1$).
- With the same seed and offset, the random stream produces deterministic results across runs.
