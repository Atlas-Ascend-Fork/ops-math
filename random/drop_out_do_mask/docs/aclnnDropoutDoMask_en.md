## Function

- Description: During training, randomly sets elements in the input to zero with probability prob, and amplifies the output by a factor of 1/(1-prob). If the corresponding bit in mask is 1, the corresponding element in the input is amplified. If the bit in mask is 0, the corresponding element in self is set to zero. In particular, if prob is 0, the elements of self remain unchanged; if prob is 1, all elements are set to 0.

- Formula:
  $$
  out_i=\begin{cases}
  0,&\text { with probability }prob \\
  \frac{1}{1-prob}self_i, &\text { with probability }1-prob
  \end{cases}
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnDropoutDoMaskGetWorkspaceSize" to obtain the workspace size required for computation and the executor that contains the computation process of the operator, and then call "aclnnDropoutDoMask" to execute the computation.
