## 功能说明

- 算子功能：返回输入张量的尺寸，即张量元素个数的整数标量。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 | 数据格式 |
| ---- | ---- | ---- | ---- | ---- |
| `x` | 输入 | 输入张量。 | 所有类型 | ND |
| `dtype` | 属性 | 可选整数，输出数据类型，取值为`DT_INT32`或`DT_INT64`，默认为`DT_INT32`。 | Int | - |
| `y` | 输出 | 输入张量的元素个数，标量。 | INT32, INT64 | ND |

## 约束说明

- `dtype`属性取值仅支持`DT_INT32`、`DT_INT64`。
