## Function

Description: Computes the backward propagation of [aclnnCircularPad3d](../../circular_pad/docs/aclnnCircularPad3d.md).

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnCircularPad3dBackwardGetWorkspaceSize" API to obtain the workspace size required for computation and the executor containing the operator computation process, and then call the "aclnnCircularPad3dBackward" API to perform the computation.

```cpp
aclnnStatus aclnnCircularPad3dBackwardGetWorkspaceSize(
    const aclTensor*   gradOutput,
    const aclTensor*   self,
    const aclIntArray* padding,
    aclTensor*         gradInput,
    uint64_t*          workspaceSize,
    aclOpExecutor**    executor)
```

```cpp
aclnnStatus aclnnCircularPad3dBackward(
    void*          workspace,
    uint64_t       workspaceSize,
    aclOpExecutor* executor,
    aclrtStream    stream)
```

## Constraints

- deterministic computation:
  - aclnnCircularPad3dBackward defaults to a deterministic implementation.

The size of the last dimension of gradOutput must satisfy the following constraints for different types:
float16/bfloat16: (0, 16362)
float32: (0, 24544)
