## Function

- Description: Clamps all elements of the input to the range [min, inf].

- Formula:

  $$
  {y}_{i} = max({{x}_{i}},{min\_value}_{i})
  $$

## Function Prototype

- aclnnClampMinTensor and aclnnInplaceClampMinTensor implement the same function. The differences are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnClampMinTensor: Creates a new output tensor object to store the computation result.
  - aclnnInplaceClampMinTensor: Stores the computation result directly in the memory of the input tensor without creating a new output tensor object.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnClampMinTensorGetWorkspaceSize" or "aclnnInplaceClampMinTensorGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the computation process. Then call "aclnnClampMinTensor" or "aclnnInplaceClampMinTensor" to perform the computation.

  auto size = GetShapeSize(shape) * sizeof(T);
  // Call aclrtMalloc to allocate memory on the device.
  auto ret = aclrtMalloc(deviceAddr, size, ACL_MEM_MALLOC_HUGE_FIRST);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMalloc failed. ERROR: %d\n", ret); return ret);

  // Call aclrtMemcpy to copy data from the host to the device.
  ret = aclrtMemcpy(*deviceAddr, size, hostData.data(), size, ACL_MEMCPY_HOST_TO_DEVICE);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMemcpy failed. ERROR: %d\n", ret); return ret);

  // Calculate the strides of the contiguous tensor.
  std::vector<int64_t> strides(shape.size(), 1);
  for (int64_t i = shape.size() - 2; i >= 0; i--) {
    strides[i] = shape[i + 1] * strides[i + 1];
  }

  // Call the aclCreateTensor API to create an aclTensor.
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
