## Function

- Description: Uses input boundary padding to pad the last dimension of the input tensor.
- Example:

    ```text
    Input tensor([[0,1,2]])
    padding([2,2])
    Output is([[0,0,0,1,2,2,2]])
    ```

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First call "aclnnReplicationPad1dGetWorkspaceSize" to obtain the workspace size required for computation and the executor containing the computation flow, and then call "aclnnReplicationPad1d" to execute the computation.

```cpp
aclnnStatus aclnnReplicationPad1dGetWorkspaceSize(
    const aclTensor*   self,
    const aclIntArray* padding,
    aclTensor*         out,
    uint64_t*          workspaceSize,
    aclOpExecutor**    executor)
```

```cpp
aclnnStatus aclnnReplicationPad1d(
    void*          workspace,
    uint64_t       workspaceSize,
    aclOpExecutor* executor,
    aclrtStream    stream)
```

    return 0;
}
