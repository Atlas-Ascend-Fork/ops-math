## Function

- Description: A hyperbolic function that returns a new tensor based on the formula. The shape of the result is the same as that of the input tensor.

- Formula:

  $$
  out=cosh(self)
  $$

## Function Prototype

aclnnCosh and aclnnInplaceCosh implement the same functionality. The differences are as follows. Select the appropriate operator based on your actual scenario.

- aclnnCosh: Requires creating a new output tensor object to store the computation result.
- aclnnInplaceCosh: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnCoshGetWorkspaceSize" or "aclnnInplaceCoshGetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor containing the operator computation process, and then call the "aclnnCosh" or "aclnnInplaceCosh" API to perform the computation.
