## Function

- Description: Converts each element in the tensor self to the remainder obtained after division by the scalar other. The result has the same sign as the divisor other, and its absolute value is less than the absolute value of other.

- Formula: The actual computation of remainder(self, other) is equivalent to the following formula:

  $$
  out_i = self_i - floor(self_i / other) * other
  $$

- Example:

  ```text
  self = tensor([[-1, -2],
                 [-3, -4]]).type(int32)
  other = 3.5   # float
  result = remainder(self, other)

  # Value of result
  # tensor([[2.5000, 1.5000],
  #         [0.5000, 3.0000]])   float

  # For the element -1 in self, the calculation result is remainder(-1, 3.5) = -1 - floor(-1 / 3.5) * 3.5 = -1 - (-1) * 3.5 = -1 + 3.5 = 2.5
  # The absolute value of the final result 2.5 is less than other 3.5.
  ```

## Function Prototype

- aclnnRemainderTensorScalar and aclnnInplaceRemainderTensorScalar implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnRemainderTensorScalar: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceRemainderTensorScalar: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First call "aclnnRemainderTensorScalarGetWorkspaceSize" or "aclnnInplaceRemainderTensorScalarGetWorkspaceSize" to obtain the workspace size required for the computation and the executor that contains the operator computation process. Then call "aclnnRemainderTensorScalar" or "aclnnInplaceRemainderTensorScalar" to execute the computation.

## Constraints

- Deterministic computation:
  - aclnnRemainderTensorScalar&aclnnInplaceRemainderTensorScalar default to a deterministic implementation.

- When the data type of self is INT32, functionality and precision within the range [-2^24, 2^24] are prioritized.
- When other is 0 and the data type of self is an integer type, the result in out is self.
