## Function

- Description: Returns a new tensor with Boolean elements, determining whether the given self and other are close to each other. If the values are close, True is returned; otherwise, False is returned.
- Formula:
  Returns a new tensor out with the data type BOOL, indicating whether each element of the input self is "close" to the corresponding element of the input other.
  Closeness is defined as:

  $$
  \left | self_{i}-other_{i}\right | \le  atol + rtol\times \left | other_{i} \right |
  $$

  The above formula holds when both self and other are finite values. When both self and other are non-finite, the result is True only if they are equal. When equal_nan is True, NaNs are considered close; when equal_nan is False, NaNs are considered not close.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First, call the "aclnnIsCloseGetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the operator computation process. Then, call the "aclnnIsClose" API to perform the computation.

```Cpp
aclnnStatus aclnnIsCloseGetWorkspaceSize(
  const aclTensor*  self,
  const aclTensor*  other,
  double            rtol,
  double            atol,
  bool              equalNan,
  aclTensor*        out,
  uint64_t*         workspaceSize,
  aclOpExecutor**   executor)
```
