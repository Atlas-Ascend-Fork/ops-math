## Function

- Description: Returns the variance computed from the values of the specified dimension of the input tensor.
- Formula: Assume dim is $i$. The calculation is performed along this dimension. $N$ is the shape of this dimension. Take $self_{i}$ and calculate the mean along this dimension $\bar{x_{i}}$.

  $$
  out = \frac{1}{max(0, N - \delta N)}\sum_{j=0}^{N-1}(self_{ij}-\bar{x_{i}})^2
  $$

  If `keepdim = true`, the dimension is retained after reduction and set to 1 in the output shape. If `keepdim = false`, the dimension is not retained.
  If dim is nullptr or [], the calculation is performed over all dimensions.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnVarCorrectionGetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the operator computation flow, and then call the "aclnnVarCorrection" API to perform the computation.

