## Function Description

- Operator function: computes the Dawson integral F(x) = exp(-x^2) * integral_0^x exp(t^2) dt.

- Computation formula:

$$F(x) = e^{-x^{2}} \int_{0}^{x} e^{t^{2}} \mathrm{d}t$$
