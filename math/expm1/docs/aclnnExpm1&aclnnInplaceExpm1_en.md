## Function

- Description: Computes the natural constant e raised to the power of the input self, and then subtracts 1 from the exponentiation result. For scenarios where self has small values, this provides higher precision than directly computing the result using the formula.
- Formula:

  $$
  out_i = {e}^{self_i} - 1
  $$

## Function Prototype

aclnnExpm1 and aclnnInplaceExpm1 implement the same functionality. The differences are as follows. Select the appropriate operator based on your actual scenario.

- aclnnExpm1: Requires creating a new output tensor object to store the computation result.
- aclnnInplaceExpm1: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First, call the "aclnnExpm1GetWorkspaceSize" or "aclnnInplaceExpm1GetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the operator computation process. Then, call the "aclnnExpm1" or "aclnnInplaceExpm1" API to perform the computation.
