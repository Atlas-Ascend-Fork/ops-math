## Function

- Description: Computes the negation of each element in the input.
- Formula:

  $$
  output_i = (-1) * self_i
  $$

## Function Prototype

Each operator uses a [two-phase APIs](../../../docs/en/context/two_phase_api.md). You must first call "aclnnNegGetWorkspaceSize" or "aclnnInplaceNegGetWorkspaceSize" to obtain the workspace size required for the computation and the executor that contains the computation flow, and then call "aclnnNeg" or "aclnnInplaceNeg" to execute the computation.

```Cpp
aclnnStatus aclnnNegGetWorkspaceSize(
    const aclTensor *self,
    aclTensor       *out,
    uint64_t        *workspaceSize,
    aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnNeg(
    void             *workspace,
    uint64_t          workspaceSize,
    aclOpExecutor    *executor,
    const aclrtStream stream)
```

```Cpp
aclnnStatus aclnnInplaceNegGetWorkspaceSize(
    aclTensor       *selfRef,
    uint64_t        *workspaceSize,
    aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnInplaceNeg(
```
