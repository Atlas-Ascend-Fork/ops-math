## Function

Returns a tensor of the same shape and type with all elements set to 1.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnInplaceOneGetWorkspaceSize" first to obtain the workspace size required for computation and the executor that contains the computation process of the operator. Then call "aclnnInplaceOne" to execute the computation.

```Cpp
aclnnStatus aclnnInplaceOneGetWorkspaceSize(
  const aclTensor*  selfRef,
  uint64_t*         workspaceSize,
  aclOpExecutor**   executor)
```

```Cpp
aclnnStatus aclnnInplaceOne(
  void*          workspace,
  uint64_t       workspaceSize,
  aclOpExecutor* executor,
  aclrtStream    stream)
```
