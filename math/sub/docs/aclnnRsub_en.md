## Function

- Description: Performs subtraction computation.
- Formula:

  $$
  out_i = other_i - self_i * alpha
  $$

## Function Prototype

Each operator uses a [two-phase APIs](../../../docs/en/context/two_phase_api.md). Call "aclnnRsubGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the operator computation process, and then call "aclnnRsub" to perform the computation.

```Cpp
aclnnStatus aclnnRsubGetWorkspaceSize(
  const aclTensor* self,
  const aclTensor* other,
  const aclScalar* alpha,
  aclTensor*       out,
  uint64_t*        workspaceSize,
  aclOpExecutor**  executor)
```

```Cpp
aclnnStatus aclnnRsub(
  void*          workspace,
  uint64_t       workspaceSize,
  aclOpExecutor* executor,
  aclrtStream    stream)
```

  return 0;
}
