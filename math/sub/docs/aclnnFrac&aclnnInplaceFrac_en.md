## Function

- Description: Computes the fractional part of each element in the input tensor and outputs the result.

- Formula:

  $$
  out_{i}=input_{i} - \lfloor \vert input_{i} \vert \rfloor * sgn(input_{i})
  $$

  Where $sgn(\cdot)$ is the sign function, which extracts the sign of $input_{i}$.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnFracGetWorkspaceSize" or "aclnnInplaceFracGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the computation flow of the operator, and then call "aclnnFrac" or "aclnnInplaceFrac" to execute the computation.

```Cpp
aclnnStatus aclnnFracGetWorkspaceSize(
  const aclTensor*  input,
  aclTensor*        out,
  uint64_t*         workspaceSize,
  aclOpExecutor**   executor)
```

```Cpp
aclnnStatus aclnnFrac(
  void*          workspace,
  uint64_t       workspaceSize,
  aclOpExecutor* executor,
  aclrtStream    stream)
```

```Cpp
aclnnStatus aclnnInplaceFracGetWorkspaceSize(
```
