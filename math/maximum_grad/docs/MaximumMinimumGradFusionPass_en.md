# MaximumMinimumGradFusionPass

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-11-11T12:43:20.232Z pushedAt=2026-11-16T06:28:26.384Z nl=2 -->

## Description

Replaces the GreaterEqual/LessEqual + Select/SelectV2 subgraphs in the graph with the MaximumGrad or MinimumGrad operator:

- When the comparison operator is GreaterEqual, it is replaced with the MaximumGrad operator; when it is LessEqual, it is replaced with the MinimumGrad operator.
- The output shape is determined by the Select branches contained in the subgraph: when the subgraph contains both the dx and dy branches, `grad_x=true, grad_y=true`, and y1 and y2 are output; when it contains only the dx branch, `grad_x=true, grad_y=false`, and only y1 is output; when it contains only the dy branch, `grad_x=false, grad_y=true`, and only y2 is output.

The graph structures before and after fusion are as follows:

![](../../../docs/en/figures/MaximumMinimumGradFusionPass.png)

After the replacement, the output shape of MaximumGrad or MinimumGrad is the result of broadcasting the input shapes, and the dtype and format are consistent with the grads input.

## Constraints

- The subgraph must be in the Maximum/Minimum gradient form generated by TensorFlow automatic differentiation, and the comparison operator node name must be under the `Maximum_grad`/`Minimum_grad` or `gradient_tape` namespace.
- The input data types must be consistent, and only float16, float32, bf16, and int32 are supported.
- The zeros input of Select/SelectV2 must be a constant node whose values are all zero.
- The fusion takes effect when the GE compiler version is 9.0.0 or later.
