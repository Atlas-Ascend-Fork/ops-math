## 功能说明

- 算子功能：返回输入张量的秩（rank），即张量的维度数，输出为INT32标量。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 | 数据格式 |
| ---- | ---- | ---- | ---- | ---- |
| `x` | 输入 | 输入张量。 | 所有类型 | ND |
| `y` | 输出 | 输入张量的维度数，标量。 | INT32 | ND |

## 约束说明

- 输入`x`支持所有数据类型和任意形状（含标量与动态shape）。
- 输出`y`恒为0维标量，数据类型固定为INT32，不随输入变化（含未知秩-2输入）。
- 输入仅支持ND格式。
