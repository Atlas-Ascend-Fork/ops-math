## Function

- Description: Performs the arctangent operation on each element of the input matrix and outputs the result.

- Formula:

  $$
  out_{i}=tan^{-1}(input_{i})
  $$

## Function Prototype

- aclnnAtan and aclnnInplaceAtan implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnAtan: Create a new output tensor object to store the computation result.
  - aclnnInplaceAtan: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnAtanGetWorkspaceSize" or "aclnnInplaceAtanGetWorkspaceSize" first to obtain the input parameters and calculate the required workspace size based on the computation flow. Then call "aclnnAtan" or "aclnnInplaceAtan" to perform the computation.

  const aclTensor *input,
