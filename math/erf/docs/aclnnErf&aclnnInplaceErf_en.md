## Function

- Description: Returns the value of the error function for each element in the input tensor.
- Formula:

$$
erf(x)=\frac{2}{\sqrt{\pi } } \int_{0}^{x} e^{-t^{2} } \mathrm{d}t
$$

## Function Prototype

aclnnErf and aclnnInplaceErf implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.

- aclnnErf: Create a new output tensor object to store the computation result.
- aclnnInplaceErf: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnErfGetWorkspaceSize" or "aclnnInplaceErfGetWorkspaceSize" API to obtain the workspace size required for the computation and the executor that contains the operator computation process, and then call the "aclnnErf" or "aclnnInplaceErf" API to execute the computation.

```Cpp
  const aclTensor*   self,

  aclOpExecutor**    executor)
```
