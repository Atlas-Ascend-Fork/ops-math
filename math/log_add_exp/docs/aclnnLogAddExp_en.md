## Function

- Description: Computes the logarithm (base e) of the sum of exponentials of the input tensors.

- Formula:

  $$
  out = \log(e^x+e^y)=\log[e^m(1+e^{-|x-y|})]=m+\log(1+e^{-|x-y|}) \quad where m=\max(x,y)
  $$

  where $x$ represents self and $y$ represents other.

## Function Prototype

 Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnLogAddExpGetWorkspaceSize" API to obtain the workspace size required for the computation and the executor containing the operator computation process. Then call the "aclnnLogAddExp" API to perform the computation.

```Cpp
aclnnStatus aclnnLogAddExpGetWorkspaceSize(
  const aclTensor*     self,
  const aclTensor*     other,
  aclTensor*           out,
  uint64_t*            workspaceSize,
  aclOpExecutor**      executor)
```

```Cpp
aclnnStatus aclnnLogAddExp(
  void*          workspace,
  uint64_t       workspaceSize,
  aclOpExecutor* executor,
  aclrtStream    stream)
```
