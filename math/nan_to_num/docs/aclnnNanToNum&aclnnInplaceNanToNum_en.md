## Function

- Description: Replaces NaN, positive infinity, and negative infinity values in the input with the values specified by nan, posinf, and neginf, respectively.

- Formula:

  $$
  \text{out}_i =
  \begin{cases}
  \text{nan} & \text{if } \text{self}_i \text{ is NaN} \\
  \text{posinf} & \text{if } \text{self}_i \text{ is } +\infty \\
  \text{neginf} & \text{if } \text{self}_i \text{ is } -\infty \\
  \text{self}_i & \text{otherwise}
  \end{cases}
  $$

## Function Prototype

- aclnnNanToNum and aclnnInplaceNanToNum implement the same functionality. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnNanToNum: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceNanToNum: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call "aclnnNanToNumGetWorkspaceSize" or "aclnnInplaceNanToNumGetWorkspaceSize" to obtain the workspace size required for the computation and the executor containing the computation process of the operator, and then call "aclnnNanToNum" or "aclnnInplaceNanToNum" to perform the computation.

  // 5. Obtain the output value. Copy the result from device-side memory to host side. Modify based on the specific API interface definition.
  auto size = GetShapeSize(selfShape);
  std::vector<float> resultData(size, 0);
  ret = aclrtMemcpy(resultData.data(), resultData.size() * sizeof(resultData[0]), selfDeviceAddr,
                    size * sizeof(resultData[0]), ACL_MEMCPY_DEVICE_TO_HOST);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("copy result from device to host failed. ERROR: %d\n", ret); return ret);
  for (int64_t i = 0; i < size; i++) {
    LOG_PRINT("result[%ld] is: %f\n", i, resultData[i]);
  }

  // 6. Release aclTensor and aclScalar. Modify based on the specific API interface definition.
  aclDestroyTensor(self);

  // 7. Release device resources. Modify based on the specific API interface definition.
  aclrtFree(selfDeviceAddr);
  if (workspaceSize > 0) {
    aclrtFree(workspaceAddr);
  }
  aclrtDestroyStream(stream);
  aclrtResetDevice(deviceId);
  aclFinalize();
  return 0;
}
