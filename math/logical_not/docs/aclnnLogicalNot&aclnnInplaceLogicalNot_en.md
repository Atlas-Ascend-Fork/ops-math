## Function

- Description: Computes the element-wise logical NOT of the given input tensor. If the output type is not specified, the output tensor is of the bool type. If the input tensor is not of the bool type, zero is regarded as False and non-zero is regarded as True.

- Formula:

$$
out[i]=
\begin{cases}
1, & \text{if } self[i]=0 \\
0, & \text{if } self[i] \ne 0
\end{cases}
$$

## Function Prototype

- aclnnLogicalNot and aclnnInplaceLogicalNot implement the same function. The differences are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnLogicalNot: A new output tensor object needs to be created to store the computation result.
  - aclnnInplaceLogicalNot: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnLogicalNotGetWorkspaceSize" or "aclnnInplaceLogicalNotGetWorkspaceSize" first to obtain the input parameters and calculate the required workspace size as instructed. Then call "aclnnLogicalNot" or "aclnnInplaceLogicalNot" to perform the computation.

    *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                              shape.data(), shape.size(), *deviceAddr);
    return 0;
}
