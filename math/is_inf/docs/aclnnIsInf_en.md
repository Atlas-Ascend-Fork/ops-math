## Function

- Description: Determines which elements in a tensor are infinite values, i.e., inf or -inf.
- Formula:

  $$
  out_i=(input_i == ±inf)
  $$

- Example:
  - If x = [9, 6, 3], the result of isinf(x) is [False, False, False].
  - If x = [[-3.14, inf], [2.7183, nan]], the result of isinf(x) is [[False, True], [False, False]].
  **NOTE** Integer types and Boolean types are bounded.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnIsInfGetWorkspaceSize" API to obtain the workspace size required for the computation and the executor that contains the operator computation process, and then call the "aclnnIsInf" API to execute the computation.

```Cpp
aclnnStatus aclnnIsInfGetWorkspaceSize(
  const aclTensor *x,
  const aclTensor *out,
  uint64_t        *workspaceSize,
  aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnIsInf(
  void          *workspace,
  uint64_t       workspaceSize,
  aclOpExecutor *executor,
  aclrtStream    stream)
```
