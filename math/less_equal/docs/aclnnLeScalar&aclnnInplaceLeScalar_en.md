## Function

- Description: Determines whether the element values in self are less than or equal to the value of other, and writes the comparison result of each element of self against the value of other into out.

- Formula:

$$
out_i = (self_i <= other) ? [True] : [False]
$$

## Function Prototype

- aclnnLeScalar and aclnnInplaceLeScalar implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnLeScalar: Create a new output tensor object to store the computation result.
  - aclnnInplaceLeScalar: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnLeScalarGetWorkspaceSize" or "aclnnInplaceLeScalarGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the operator computation process. Then call "aclnnLeScalar" or "aclnnInplaceLeScalar" to execute the computation.

```Cpp
  const aclTensor*          self,

```

```Cpp
  auto size = GetShapeSize(selfShape);
  std::vector<float> resultData(size, 0);
  ret = aclrtMemcpy(resultData.data(), resultData.size() * sizeof(resultData[0]), selfDeviceAddr, size * sizeof(float),
                    ACL_MEMCPY_DEVICE_TO_HOST);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("copy result from device to host failed. ERROR: %d\n", ret); return ret);
  for (int64_t i = 0; i < size; i++) {
    LOG_PRINT("result[%ld] is: %f\n", i, resultData[i]);
  }

  aclDestroyTensor(self);
  aclDestroyScalar(other);

  // 7. Release device resources.
  aclrtFree(selfDeviceAddr);
  if (workspaceSize > 0) {
    aclrtFree(workspaceAddr);
  }
  aclrtDestroyStream(stream);
  aclrtResetDevice(deviceId);
  aclFinalize();
  return 0;
}
```
