## Function

- Description: Performs division and floors the result.
- Formula:

  $$
  out_i = floor(\frac{self_i}{other_i})
  $$

## Function Prototype

aclnnFloorDivide and aclnnInplaceFloorDivide implement the same function. The differences are as follows. Choose the appropriate operator based on your actual scenario.

- aclnnFloorDivide: Requires creating a new output tensor object to store the computation result.
- aclnnInplaceFloorDivide: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnFloorDivideGetWorkspaceSize" or "aclnnInplaceFloorDivideGetWorkspaceSize" first to obtain the workspace size required for computation and the executor containing the operator computation process. Then call "aclnnFloorDivide" or "aclnnInplaceFloorDivide" to perform the computation.

```Cpp
  const aclTensor*   self,
  const aclTensor*   other,
  aclTensor*         out,
  uint64_t*          workspaceSize,
  aclOpExecutor**    executor)
```

## Constraints

- Deterministic computation: aclnnFloorDivide&aclnnInplaceFloorDivide default to a deterministic implementation.

<!-- npu="A3,910b" id9 -->
- <term>Atlas A2 products</term>, <term>Atlas A3 products</term>   : Due to the limited precision of FLOAT16/BFLOAT16 data types, not all decimals can be represented, resulting in certain errors during floor division. You can choose a higher-precision data type such as FLOAT32.

```Cpp
  return 0;
}
```
