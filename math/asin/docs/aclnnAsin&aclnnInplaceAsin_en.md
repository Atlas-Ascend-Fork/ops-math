## Function

- Description: Performs the arcsine operation on each element of the input matrix and outputs the result.

- Formula:

  $$
  out_{i}=sin^{-1}(input_{i})
  $$

## Function Prototype

- aclnnAsin and aclnnInplaceAsin implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnAsin: Create a new output tensor object to store the computation result.
  - aclnnInplaceAsin: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnAsinGetWorkspaceSize" or "aclnnInplaceAsinGetWorkspaceSize" to obtain the workspace size required for computation and the executor that contains the computation process of the operator, and then call "aclnnAsin" or "aclnnInplaceAsin" to perform the computation.
