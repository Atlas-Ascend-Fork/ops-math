## Function

- Description: Computes the bitwise XOR operation of each element in input tensor self and the element at the corresponding position in input tensor other. Both self and other must be of the integer or boolean type. For the boolean type, the logical XOR is computed.

- Formula:

  $$
  \text{out}_i =
  \text{self}_i \, \bigoplus\, \text{other}_i
  $$

## Function Prototype

aclnnBitwiseXorTensor and aclnnInplaceBitwiseXorTensor implement the same function. The usage differences are as follows. Choose an appropriate operator based on your actual use case.

- aclnnBitwiseXorTensor: a new output tensor object needs to be created to store the computation result.
- aclnnInplaceBitwiseXorTensor: no need to create a new output tensor object; the computation result is directly stored in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnBitwiseXorTensorGetWorkspaceSize" or "aclnnInplaceBitwiseXorTensorGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the computation process of the operator, and then call "aclnnBitwiseXorTensor" or "aclnnInplaceBitwiseXorTensor" to perform the computation.
