## Function

- Description: Computes the natural logarithm.

- Formula:

$$
output_i=log_e(self_i)
$$

## Function Prototype

- aclnnLog and aclnnInplaceLog implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnLog: Create a new output tensor object to store the computation result.
  - aclnnInplaceLog: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnLogGetWorkspaceSize" or "aclnnInplaceLogGetWorkspaceSize" first to obtain the workspace size required for computation and the executor containing the operator computation process. Then call "aclnnLog" or "aclnnInplaceLog" to perform the computation.

```Cpp
aclnnStatus aclnnLogGetWorkspaceSize(
  const aclTensor*          self,
  aclTensor*                out,
  uint64_t*                 workspaceSize,
  aclOpExecutor**           executor)
```

```Cpp

```

## Constraints

- Deterministic computation:
  - aclnnLog&aclnnInplaceLog default to a deterministic implementation.

If the input shape exceeds 1000000, operator execution may time out (aicore error, errorStr: timeout or trap error). This occurs when the product of the last 2 dimensions is less than 16 and the product of the preceding dimensions is too large.

                    aclDataType dataType, aclTensor** tensor) {
  auto size = GetShapeSize(shape) * sizeof(T);
  // Call aclrtMalloc to allocate memory on the device.
  auto ret = aclrtMalloc(deviceAddr, size, ACL_MEM_MALLOC_HUGE_FIRST);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMalloc failed. ERROR: %d\n", ret); return ret);
  // Call aclrtMemcpy to copy data from the host to the device memory.
  ret = aclrtMemcpy(*deviceAddr, size, hostData.data(), size, ACL_MEMCPY_HOST_TO_DEVICE);
  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("aclrtMemcpy failed. ERROR: %d\n", ret); return ret);

  // Compute the strides of the contiguous tensor.
  std::vector<int64_t> strides(shape.size(), 1);
  for (int64_t i = shape.size() - 2; i >= 0; i--) {
    strides[i] = shape[i + 1] * strides[i + 1];

  // Call the aclCreateTensor API to create an aclTensor.
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
