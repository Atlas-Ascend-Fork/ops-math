## Function

- Description: Performs an inverse hyperbolic cosine operation on each element of the input tensor and outputs the result.

- Formula:

  $$
  out=cosh^{-1}(self)
  $$

## Function Prototype

- aclnnAcosh and aclnnInplaceAcosh implement the same functionality. The differences are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnAcosh: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceAcosh: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnAcoshGetWorkspaceSize" or "aclnnInplaceAcoshGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor containing the computation flow of the operator, and then call "aclnnAcosh" or "aclnnInplaceAcosh" to execute the computation.
