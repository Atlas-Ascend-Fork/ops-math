## Function

- Operator function: Activation function. Returns a tensor with the same shape as the input tensor, performing element-wise computation on the input tensor.

- Formula:

$$
tanh(self)=\frac{e^{self}-e^{-self}}{e^{self} + e^{-self}}
$$

## Function Prototype

- aclnnTanh and aclnnInplaceTanh implement the same functionality. The differences are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnTanh: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceTanh: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnTanhGetWorkspaceSize" or "aclnnInplaceTanhGetWorkspaceSize" API to obtain the workspace size required for computation and the executor containing the computation process of the operator, and then call the "aclnnTanh" or "aclnnInplaceTanh" API to perform the computation.
