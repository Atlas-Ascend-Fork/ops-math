## Function

- Description: Returns a new tensor with the reciprocal of each input element.

- Formula:

$$
out = {\frac{1} {input}}
$$

- Example:

  input = tensor([1,2,3,4]). After the reciprocal computation, out = tensor([1.00, 0.50, 0.33, 0.25]).

## Function Prototype

- aclnnReciprocal and aclnnInplaceReciprocal implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnReciprocal: A new output tensor object needs to be created to store the computation result.
  - aclnnInplaceReciprocal: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnReciprocalGetWorkspaceSize" or "aclnnInplaceReciprocalGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor that contains the operator computation process. Then call "aclnnReciprocal" or "aclnnInplaceReciprocal" to execute the computation.

```Cpp
aclnnStatus aclnnReciprocalGetWorkspaceSize(
  const aclTensor* self,
  aclTensor*       out,
  uint64_t*        workspaceSize,
  aclOpExecutor**  executor)
```
