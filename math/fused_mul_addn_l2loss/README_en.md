## Function Description

- Operator function: fuses the scalar multiply-add and L2 Loss computation. The operator performs the multiply-add operation element-wise on the input tensor to obtain y1, and at the same time performs the full squared reduction on x1 to obtain y2 (a single-element scalar). This operator is an internal operator of GE graph fusion (generated by fusing the `Mul + AddN + L2Loss` subgraph).

- Computation formula:

$$
y_1 = x_1 \times x_3[0] + x_2
$$

$$
y_2 = \sum \frac{x_1^2}{2}
$$

## Constraint Description

- The shapes of x1 and x2 must be the same (InferShape checks dimension by dimension, and tiling checks the number of elements).
- The data types of x1/x2/x3/y1/y2 must be the same, and only FLOAT and FLOAT16 are supported.
- FLOAT16 support scope: the kernel path supports FLOAT16, but the graph-mode path does not.
- x3 is a single-element scalar tensor (must contain exactly 1 element), and only x3[0] is taken during computation. InferShape and tiling check the number of elements, and an empty x3 is rejected.
- y2 is a single-element scalar output (shape (1,)), and its data type is the same as that of x1.
- For the FLOAT16 data type, the y2 result overflows when it exceeds 65504 (consistent with the built-in 910b implementation, and this is an inherent limitation of the data type).
- This operator does not provide an aclnn API and supports only graph-mode invocation.
