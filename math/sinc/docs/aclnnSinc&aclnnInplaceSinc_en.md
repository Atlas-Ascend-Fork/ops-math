## Function

- Operator function: Performs sinc operation on the input tensor.

- Formula:

  $$
  out_i =
  \begin{cases}
  1,\quad self_i = 0\\
  \sin(\pi*self_i)/(\pi*self_i),\quad otherwise\\
  \end{cases}
  $$

## Function Prototype

- aclnnSinc and aclnnInplaceSinc implement the same functionality. The differences are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnSinc: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceSinc: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the first-phase API "aclnnSincGetWorkspaceSize" or "aclnnInplaceSincGetWorkspaceSize" to obtain the input parameters and calculate the required workspace size based on the computing process, and then call the second-phase API "aclnnSinc" or "aclnnInplaceSinc" to execute the computation.
