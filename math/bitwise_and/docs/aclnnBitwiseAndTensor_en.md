## Function

- Description: When the input is a BOOL-type tensor, performs a logical AND operation; when the input is an INT-type tensor, performs a bitwise AND operation.

- Formula:

  $$
  out_i = self_i \& other_i
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnBitwiseAndTensorGetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the computation process of the operator, and then call the "aclnnBitwiseAndTensor" API to perform the computation.

```Cpp
aclnnStatus aclnnBitwiseAndTensorGetWorkspaceSize(
  const aclTensor*            self,
  const aclTensor*            other,
  aclTensor*                  out,
  uint64_t*                   workspaceSize,
  aclOpExecutor**             executor)
```

```Cpp
aclnnStatus aclnnBitwiseAndTensor(
  void*                   workspace,
  uint64_t                workspaceSize,
  aclOpExecutor*          executor,
  aclrtStream             stream)
```
