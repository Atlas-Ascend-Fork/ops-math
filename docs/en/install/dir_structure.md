# Project Directory

> Some directories listed in this chapter are optional. Refer to the actual deliverables. In particular, the deliverables of a **single-operator directory** vary by use case, as described below:
>
> - If the op_host directory is missing, the operator may call the op_host implementation of another operator. For the call logic, see the source code in the op_api or op_graph directory of the operator. Alternatively, the kernel may not have an Ascend C implementation yet. If needed, developers are welcome to contribute the operator by referring to the [Contribution Guide](../../../CONTRIBUTING.md).
> - If the op_kernel directory is missing, the operator may call the op_kernel implementation of another operator. For the call logic, see the source code in the op_api or op_graph directory of the operator. Alternatively, the kernel may not have an Ascend C implementation yet. If needed, developers are welcome to contribute the operator by referring to the [Contribution Guide](../../../CONTRIBUTING.md).
> - If the op_api directory is missing, the operator does not support aclnn calls yet.
> - If the op_graph directory is missing, the operator does not support graph mode calls yet.

The full project directory hierarchy is described as follows:

