## 功能说明

- 算子功能：不做任何操作，仅用作控制边的占位符。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 | 数据格式 |
| ---- | ---- | ---- | ---- | ---- |
| 无 | - | NoOp无输入、输出和属性。 | - | - |

## 约束说明

- NoOp无数据输入和输出，仅支持作为控制边占位符使用。
