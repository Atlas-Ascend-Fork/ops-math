## 功能说明

- 算子功能：根据`branch_index`的值选择一个子图分支执行，将输入张量传递给所选子图并返回其输出张量。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 | 数据格式 |
| ---- | ---- | ---- | ---- | ---- |
| `branch_index` | 输入 | 选择子图分支的索引，为INT32标量。 | INT32 | ND |
| `input` | 输入（动态） | 传递给所选子图的输入张量，支持动态输入。 | 所有类型 | ND |
| `branches` | 子图（动态） | 子图分支列表，每个子图接收`input`并返回一组张量。 | - | - |
| `output` | 输出（动态） | 所选子图返回的输出张量，支持动态输出。 | 所有类型 | ND |

## 约束说明

- `branch_index`必须为INT32标量（rank为0）。
- `branches`中各子图的输出类型需保持一致。
